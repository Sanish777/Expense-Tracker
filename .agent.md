# Project Context
This is the "Wise Expense" app, a local-first, sleek expense tracker built with Flutter.
It uses SQLite (via sqflite), Provider for state management, and modern UI elements.

# CRITICAL RULES FOR THE AI AGENT
1. **Always Build Releases**: You must execute a release build (`flutter run -d <iphone_device_id> --release` or `flutter build ios --release`) after every prompt and code change to ensure the user can immediately test the changes on their physical device.
2. **Keep UI Aesthetic**: Maintain the black & white sleek minimalist design, ensuring system Dark/Light mode support. Do not regress into using the old purple `.primaryGradient` UI elements.
3. **Database Rules**: Be very careful when handling SQLite `.db` paths. Always reference `getDatabasesPath()` and ensure connections are closed before file operations like import/export are performed.
